# Rivan Parikh — Personal Portfolio

A responsive, résumé-driven portfolio built with HTML, CSS, and JavaScript. It highlights my engineering experience, project case studies, technical skills, education, and contact information.

The site includes accessible navigation, responsive layouts, structured search metadata, a custom social-sharing card, and privacy-friendly event tracking for résumé, project, and contact clicks.

## Local preview

Serve the repository root with any static file server. For example:

```sh
python3 -m http.server 4173
```

Then open `http://localhost:4173/`.

## Deployment

The site is structured to deploy directly from the repository root. On Netlify, leave the build command empty and set the publish directory to `.`.

## Analytics

Page views and labeled interaction events use [Simple Analytics](https://www.simpleanalytics.com/), which does not use cookies or collect personal data. Add the deployed portfolio domain to a Simple Analytics account to access the dashboard and configure goals.
